# 카메라 기반 감정/표정 분석 모듈 — 진행 메모

담당: 김도현 (카메라 관련 모델 개발)

## 요구사항
1. 카메라로 환자 표정 분석, 감정 상태 분류
2. 최근 일정 기간 감정 변화 비율 기록 → 정서 변화 추이 확인
3. AI Hub 감정 분류 데이터셋 검토

## 논의 중: 분류 카테고리를 뭐로 잡을지

- 일반 FER 7종(분노/혐오/공포/행복/슬픔/놀람/중립) vs
- 기획서 타겟 3종(통증/불안/무기력) + 평온(baseline) 직접 설계
- 파킨슨 환자(시나리오3, 사토)는 가면양 얼굴(hypomimia)로 표정 기반 인식이
  구조적으로 어려울 수 있음 — 예외 케이스로 문서화 필요

## 프로토타입 (1차, face-emotion/emotion_trend_tracker.py)

사전학습 FER 모델로 7종 감정 분류 + 슬라이딩 윈도우 기준 감정 비율 집계.
공포+놀람 → 불안 프록시, 슬픔+중립 → 무기력 프록시로 매핑.
자세/낙상 감지 모듈과 동일한 이벤트 스키마 사용.
