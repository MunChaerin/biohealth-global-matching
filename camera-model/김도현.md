# 카메라 - 표정/감정 분석 — 김도현

이 브랜치(feature/facial-emotion)는 표정/감정 분석 모듈만 다룸.
자세/낙상 감지, 알약 인식은 각각 별도 브랜치에서 진행.

## 폴더 구조

```
camera-model/
├── face-emotion/
│   ├── landmark_expression_tracker.py   # 메인: MediaPipe 랜드마크 + 규칙 (v2)
│   ├── expression_rules.py              # 지표 계산 + 프록시 규칙
│   ├── evaluate_runs.py                 # 라벨 테스트 재채점
│   ├── emotion_trend_tracker.py         # FER 방식 (보류)
│   └── README.md                        # 실행 방법, 로그 구조
├── docs/
│   └── 표정감정_설계.md                  # 설계, 한계점, 전체 개발 목록
└── 김도현.md
```
